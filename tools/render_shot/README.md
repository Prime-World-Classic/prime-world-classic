# render_shot

Визуальный гейт рендер-этапов плана NVRHI (`docs/PLAN_NVRHI.md` §2.8).

Логи и дампы не показывают, что картинка поехала: неверный порядок аргументов
draw, неверный вьюпорт или подставленный шейдер молча рисуют мусор, а E2E при
этом зелёный. Отсюда — сравнение кадров, снятых с ВМС по VNC.

Кадр снимает существующий инструмент (не дублируем):

```sh
python3 /home/rekon/PW/vm7/vncshot.py 127.0.0.1 5918 /tmp/shot.ppm
```

Дальше этот инструмент:

```sh
python3 ppm_tools.py diff /tmp/shot.ppm /tmp/ref.ppm [--tol 8] [--limit 0]
python3 ppm_tools.py png  /tmp/shot.ppm /tmp/shot.png    # посмотреть глазами
```

`diff` печатает долю отличающихся пикселей (порог `--tol` на канал), максимум
дельты и координаты первого отличия; код выхода ненулевой, если доля выше
`--limit`. `--limit 0` уместен только для сравнения «до/после» в один и тот же
момент прогона: кадр боя не детерминирован (таймер, позиция юнита, партиклы).

Процедура и тайминги — скил `.pi/skills/pw-client`, «Скриншот-гейт рендера».
