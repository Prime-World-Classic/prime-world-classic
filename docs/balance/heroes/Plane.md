# Авиатор (Plane)

**Роль:** стрелок дальнего боя с дешёвым AoE-залпом (ракеты), сильной мобильностью и ультой-бомбардировкой с неуязвимостью в полёте.

## Статы
- Energy 725 / 1197.5 (+16% / +11% к среднему) — самый большой ресурс в наборе; Life 810 / 1965 (−11% на ур.1, −2% на ур.36): ранняя игра хрупкая.
- Stamina 45 / 67.75 (−16% / −6%) и Will 43 / 62.25 (−20% / −15%) — слабая броня против обоих типов урона; MoveSpeed 50 (−3%).
- Strength 76 (+2%), Intellect 75 (+1%), Dexterity 72.2 (+6%) — около среднего; AttackSpeed 67.7 (−2%). Range 14 — дальний бой.

## Таланты
### A1 — Ракетный удар (активный, КД 10 с, 70 энергии, дальность 14)
- Эффект: ракета по области радиусом 5, урон Energy: damageScale(Int, 63→473) = 122 при Int 80 и 359 при 200. Дальность 14 при Str ≥ Int, иначе 19 + Int/80. На КД: 12.2 / 35.9 урона в сек; на 100 энергии: 174 / 513. Лужа по формуле даёт 62 / 180 за 3 с, но в XML у spell_A1_DoT нет аппликатора урона. Стан 0.5 с (по тексту, при Str > Int) в XML не найден.
- Улучшения/альтернатива: A1u — вторая ракета в течение 5 с с обнулением КД, то есть два залпа за один КД: 244 / 718. Альтернативы нет.
- Оценка: сильно — дешёвый AoE с коротким КД, главный источник урона героя.

### A2 — Шквальный огонь (активный, КД 14 с, 80 энергии, на себя)

- Улучшения/альтернатива: A2u — +10 / +34 Проворства (или Хитрости, если Int > Str) на время действия.
- Оценка: нормально — урон средний, лечение сильное, но только на родной земле.

### A0 — Сверхманёвренность (пассивный)
